# CogniLink 社交媒体内容生成插件 - 开发记录

## 项目概述

CogniLink是一个Obsidian插件，旨在将用户的笔记库转化为高质量的社交媒体内容。本项目基于现有的RAG服务、AI服务和聊天界面，扩展社交媒体内容生成功能。

## 需求拆解与Linear任务管理

### 总体架构
基于需求设计文档，我们将功能拆解为5个主要Feature，每个Feature下包含若干具体的Task。
