# cursor 开发需求管理

### 优化后的答案

以下是针对在“vibe coding”模式下使用 Cursor 和 Linear（通过 Linear MCP 集成）进行需求和提示管理的优化解决方案。解决方案包括设置 Linear MCP、需求和提示模板、开发流程指南以及如何高效管理需求和提示，以提高开发效率并减少需求混淆和上下文遗忘。

**关键点：**

- **Linear MCP 集成**：通过 Linear 的 Model Context Protocol (MCP) 服务器，Cursor 可以直接与 Linear 交互，获取需求详情、创建或更新任务。
- **需求管理**：在 Linear 中以用户故事形式创建结构化需求，确保清晰且可追溯。
- **提示工程**：使用标准化提示模板，结合 Linear 需求详情，提高代码生成效率。
- **上下文保留**：通过代码注释和 Linear 更新，保持需求与代码的关联，防止信息丢失。
- **注意事项**：AI 生成的代码需人工审查，提示需持续优化以减少误解。

### 设置 Linear MCP

在 Cursor 中配置 Linear MCP 服务器以实现与 Linear 的无缝集成：

1. 打开 Cursor，按 `Ctrl+Shift+J` 进入设置。
2. 选择“MCP”选项，点击“添加新的全局 MCP 服务器”。
3. 输入服务器 URL：`https://mcp.linear.app/sse`。
4. 根据提示使用 Linear 账户进行身份验证（可能需要 API 密钥）。
5. 确认服务器状态为绿色，表示连接成功。

### 需求模板

在 Linear 中创建结构化的需求（以问题形式），确保清晰且适合 AI 辅助开发：

- **标题**：简洁描述功能或任务（例如，“实现用户注册”）。
- **描述**：
    - **用户故事**：以“作为[用户类型]，我想[目标]，以便[原因]”格式描述。
    - **验收标准**：列出功能完成的具体条件。
    - **技术说明**：指定技术栈、数据库或其他约束。
- **标签**：用于分类（例如，“前端”、“后端”）。
- **负责人**：分配给团队成员。
- **状态**：跟踪进度（例如，“待办”、“进行中”、“完成”）。

**示例需求**：

- **标题**：实现用户注册
- **描述**：
    - **用户故事**：作为新用户，我想注册账户，以便访问平台功能。
    - **验收标准**：
        - 接受邮箱和密码。
        - 验证邮箱唯一性和格式。
        - 密码至少 8 个字符。
        - 注册成功后重定向到登录页面。
    - **技术说明**：
        - 使用 Flask 后端。
        - 数据存储在 PostgreSQL。
        - 实现密码哈希。
- **标签**：后端、用户认证
- **负责人**：张三
- **状态**：待办

### 提示模板

在 Cursor 中使用标准化的提示模板，结合 Linear MCP 获取需求详情，确保生成代码符合需求：

- **格式**：
    
    ```

    ```


### 开发流程

1. **需求创建**：
    - 在 Linear 中创建问题，遵循需求模板。
    - 分配问题 ID（例如，PROJ-123）。
2. **提示生成**：
    - 在 Cursor 的 Composer 功能中，使用提示模板，引用问题 ID。
    - 通过 Linear MCP 自动获取问题详情，或手动粘贴描述。
3. **代码生成与审查**：
    - 使用 Cursor 生成代码，检查是否符合验收标准。
    - 在代码中添加注释，引用问题 ID（例如，`# 实现 PROJ-123: 用户注册`）。
4. **需求追踪**：
    - 使用 Linear MCP 更新问题状态或添加评论（例如，“代码已生成，提交链接：[...]”）。
    - 在项目仓库中记录需求、提示和代码的映射。
5. **版本控制**：
    - 使用 Git 管理代码、需求文档和提示，存储在项目仓库的 `requirements/` 和 `prompts/` 目录中。
6. **上下文保留**：
    - 在 `docs/interaction_logs.md` 中记录 AI 交互和关键决策。
    - 定期备份 Cursor 的聊天历史数据库。

### 提示管理

- **提示库**：在项目仓库的 `prompts/` 目录中存储通用提示模板，按功能模块组织（例如，`prompts/auth/register.md`）。
- **版本控制**：使用 Git 跟踪提示更改，记录优化历史。
- **共享与复用**：团队成员共享提示库，确保一致性。
- **优化**：根据 AI 响应调整提示，记录改进过程。

### Linear 和 Cursor 需求与提示管理指南

以下是详细的指导手册，涵盖如何在全栈敏捷开发中使用 Linear 和 Cursor（通过 Linear MCP 集成）进行需求和提示管理，优化“vibe coding”流程，提高效率并确保需求一致性。

### 1. Linear MCP 集成的功能与设置

**功能**：
Linear 的 MCP 服务器（`https://mcp.linear.app/sse`）允许 Cursor 通过 Model Context Protocol (MCP) 与 Linear 交互，支持以下操作：

- **获取问题详情**：使用 `get_issue` 工具，通过问题 ID 获取标题、描述、验收标准等。
- **列出问题**：使用 `list_issues` 工具，过滤团队、负责人或状态。
- **创建/更新问题**：使用 `create_issue` 和 `update_issue` 工具，添加新任务或更新状态/评论。
- **其他功能**：列出团队（`list_teams`）和项目（`list_projects`），支持更复杂的自动化工作流。

**设置步骤**：

1. 打开 Cursor，按 `Ctrl+Shift+J` 进入设置。
2. 选择“MCP”选项，点击“添加新的全局 MCP 服务器”。
3. 输入服务器 URL：`https://mcp.linear.app/sse`。
4. 根据提示登录 Linear 账户或提供 API 密钥（可在 [Linear API 设置](https://linear.app/settings/api) 获取）。
5. 确认服务器状态为绿色，表示连接成功。
6. 在 Cursor 的 Composer 功能中测试工具，例如输入“使用 Linear MCP 列出我的待办问题”。

**限制**：

- 需要稳定的网络连接以访问远程 MCP 服务器。
- 部分功能（如批量操作）可能仍在开发中，需关注 [Linear 变更日志](https://linear.app/changelog/2025-05-01-mcp)。
- API 密钥管理需谨慎，确保安全存储。

### 2. 需求管理方法与最佳实践

**方法论**：
在敏捷开发中，推荐以下方法适应“vibe coding”的动态特性：

- **用户故事**：以“作为[用户]，我想[功能]，以便[目标]”格式定义需求，附带验收标准。
- **看板（Kanban）**：通过 Linear 的看板视图（待办、进行中、完成）管理任务，支持快速迭代。
- **持续反馈**：通过迭代审查 AI 生成代码，及时调整需求。

**最佳实践**：

- **清晰上下文**：需求描述需包含技术栈、约束和验收标准，减少 AI 误解。
- **模块化需求**：将复杂功能拆分为小任务，便于 AI 处理。
- **文档化**：在 Linear 中记录需求详情，在 Cursor 中记录交互日志。

**需求模板**：
在 Linear 中创建问题时，使用以下结构：

- **标题**：简洁描述（例如，“实现用户注册”）。
- **描述**：
    - **用户故事**：明确用户需求。
    - **验收标准**：列出可测试的条件。
    - **技术说明**：指定实现细节。
- **标签**：分类任务（例如，“后端”、“用户认证”）。
- **负责人**：分配开发人员。
- **状态**：跟踪进度。
