# 用户反馈与错误处理

## 技术实现方案

### 1. 用户反馈机制
- 使用 Obsidian 的 Notice API 提示用户操作结果（如 new Notice('操作成功')）。
- 关键路径（如笔记读取、AI 调用、配置保存）均需有用户可见反馈。
- 重要日志可写入控制台，便于开发调试。

### 2. 错误处理
- 统一 try-catch 捕获异步操作异常。
- 错误信息通过 Notice/日志反馈给用户和开发者。
- 可封装 ErrorService 统一处理异常和日志。

### 3. 单元测试
- 使用 Jest 测试 Notice 调用与异常处理分支。
- Mock Notice/console，验证用户反馈与日志输出。

### 4. 参考代码结构
```typescript
import { Notice } from 'obsidian';

try {
  // 可能出错的操作
} catch (e) {
  console.error(e);
  new Notice('操作失败，请重试');
}
```
