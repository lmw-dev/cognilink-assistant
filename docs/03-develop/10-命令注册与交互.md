# 命令注册与交互

## 技术实现方案

### 1. 命令注册
- 使用 `this.addCommand` 在插件 onload 中注册命令。
- 命令 id、name、回调函数分离，便于维护和扩展。
- 支持命令面板、快捷键触发。

### 2. 命令与服务/视图解耦
- 命令回调仅负责调度，具体逻辑委托服务层或 UI 层。
- 便于后续扩展更多命令。

### 3. 单元测试
- 使用 Jest 测试命令注册与回调逻辑。
- Mock Obsidian API，验证命令触发与服务调用。

### 4. 参考代码结构
```typescript
this.addCommand({
  id: 'start-new-chat',
  name: '新建聊天',
  callback: () => {
    // 调用 ChatService 或 UI 层新建会话
  }
});

this.addCommand({
  id: 'check-originality',
  name: '检查原创性',
  callback: () => {
    // 调用 OriginalityService 检查当前笔记
  }
});
```
