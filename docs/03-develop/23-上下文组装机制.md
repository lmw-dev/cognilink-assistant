## 1. 详尽需求描述

### 1.1 上下文组装机制

- **目标**：在生成 LLM Prompt 时，自动组装上下文，优先插入“钉住”内容，再补充高相关内容，超出 Token 限制时自动截断或摘要，确保最重要信息优先保留。
- **功能点**：
  - 支持用户在 UI 上“钉住”某些内容（如笔记、片段），这些内容始终优先插入 Prompt。
  - 检索相关内容时，按相关性排序，依次补充到上下文。
  - 组装时动态计算 Token 总数，超限时自动裁剪（优先保留 pinned，相关内容可摘要或丢弃）。
  - 支持多 Provider（OpenAI/Anthropic）Token 计算规则。
  - 提供 UI 交互（如 pin 按钮），让用户可手动钉住/取消钉住内容。

### 1.2 Token 管理

- **目标**：确保组装的上下文不会超出 LLM 的最大 Token 限制，兼容不同 Provider 的 Token 计算方式。
- **功能点**：
  - 针对 OpenAI/Anthropic，分别实现 Token 估算函数。
  - 组装上下文时，动态计算剩余 Token 空间，优先插入 pinned，再插入相关内容，超限时自动裁剪或摘要。
  - Token 计算逻辑可扩展，便于后续支持更多 Provider。
  - 支持在 UI 上显示当前 Token 使用量和剩余空间。

## 3. 具体代码实现

### 3.1 Token 工具（src/utils/tokenUtils.ts）

```ts
export function countTokens(text: string, provider: 'openai' | 'anthropic'): number {
  if (!text) return 0;
  if (provider === 'openai') return Math.ceil(text.length / 4);
  if (provider === 'anthropic') return Math.ceil(text.length / 3.5);
  return text.length;
}
```

### 3.2 上下文组装工具（src/utils/ContextAssembler.ts）

```ts
import { countTokens } from './tokenUtils';

export interface ContextPiece {
  id: string;
  content: string;
  pinned?: boolean;
  tokens?: number;
  summary?: string;
}

export interface AssembleContextOptions {
  pieces: ContextPiece[];
  maxTokens: number;
  provider: 'openai' | 'anthropic';
  summaryFn?: (content: string) => Promise<string>; // 可选摘要函数
}

export async function assembleContext({
  pieces,
  maxTokens,
  provider,
  summaryFn
}: AssembleContextOptions): Promise<{ context: string; usedTokens: number; dropped: ContextPiece[] }> {
  // 1. 先插入 pinned
  const pinned = pieces.filter(p => p.pinned);
  const others = pieces.filter(p => !p.pinned).sort((a, b) => (b.tokens ?? 0) - (a.tokens ?? 0));
  let context = '';
  let usedTokens = 0;
  const dropped: ContextPiece[] = [];

  // 插入 pinned
  for (const p of pinned) {
    const t = countTokens(p.content, provider);
    if (usedTokens + t > maxTokens) break;
    context += p.content + '\n';
    usedTokens += t;
  }

  // 插入相关内容
  for (const p of others) {
    const t = countTokens(p.content, provider);
    if (usedTokens + t > maxTokens) {
      // 超限时尝试摘要
      if (summaryFn) {
        const summary = await summaryFn(p.content);
        const st = countTokens(summary, provider);
        if (usedTokens + st <= maxTokens) {
          context += summary + '\n';
          usedTokens += st;
          continue;
        }
      }
      dropped.push(p);
      continue;
    }
    context += p.content + '\n';
    usedTokens += t;
  }

  return { context: context.trim(), usedTokens, dropped };
}
```

## 1. 主流程集成设计

### 1.1 典型主流程（如 RAG 检索/内容整合/生成）

**步骤：**
1. 检索相关内容，得到 `Note[]` 或 `ContextPiece[]`。
2. 用户可在 UI 上“钉住”部分内容（如点击 pin 按钮，标记 `pinned: true`）。
3. 组装上下文时，调用 `assembleContext`，传入所有内容、maxTokens、provider。
4. 得到最终上下文字符串、已用 Token、被丢弃内容。
5. 用于 Prompt 模板渲染，传递给 LLM 生成。

**伪代码示例：**
```ts
import { assembleContext, ContextPiece } from './utils/ContextAssembler';
import { countTokens } from './utils/tokenUtils';

// 1. 检索相关内容
const notes: Note[] = await embeddingService.findRelevantNotes(query, topK, threshold);

// 2. 转为 ContextPiece，带 pinned 状态
const pieces: ContextPiece[] = notes.map(n => ({
  id: n.path,
  content: n.content,
  pinned: pinnedIds.has(n.path), // pinnedIds 由 UI 维护
}));

// 3. 组装上下文
const { context, usedTokens, dropped } = await assembleContext({
  pieces,
  maxTokens: settings.ai.maxTokens,
  provider: settings.ai.provider,
  summaryFn: async (content) => content.slice(0, 100) + '...' // 可用 LLM 摘要
});

// 4. 用于 Prompt 渲染
const prompt = promptTemplateService.render(template, {
  theme: query,
  context,
  pinned: pieces.filter(p => p.pinned).map(p => p.content).join('\n')
});
```
