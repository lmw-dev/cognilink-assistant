# 主题系统与样式实现

## 1. 概述

为了确保插件与 Obsidian 的视觉体验一致，我们实现了完整的主题系统和基础样式。主要包括主题管理、样式变量系统、基础组件样式等。

## 2. 主要实现

### 2.1 主题管理器 (ThemeManager)

```typescript
class ThemeManager {
  private currentTheme: Theme = 'light';
  private observers: ThemeObserver[] = [];

  // 加载主题
  private loadTheme() {
    const savedTheme = localStorage.getItem('theme') as Theme | null;
    if (savedTheme) {
      this.setTheme(savedTheme);
    } else {
      this.setTheme(this.getSystemTheme());
    }
  }

  // 监听系统主题变化
  private listenToSystemThemeChanges() {
    window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', e => {
      if (!localStorage.getItem('theme')) {
        this.setTheme(e.matches ? 'dark' : 'light');
      }
    });
  }
}
```

## 3. 特性

1. 主题适配
   - 支持明暗主题自动切换
   - 响应系统主题变化
   - 支持手动切换主题
   - 主题持久化存储

2. 样式系统
   - 统一的变量命名规范
   - 响应式布局支持
   - 动画过渡效果
   - 组件样式封装

3. 可扩展性
   - 支持自定义主题配置
   - 组件样式可覆盖
   - 主题变化事件订阅机制

## 4. 使用示例

### 4.1 主题切换

```typescript
// 获取当前主题
const currentTheme = themeManager.getCurrentTheme();

// 切换主题
themeManager.toggleTheme();

// 订阅主题变化
const unsubscribe = themeManager.subscribe(theme => {
  console.log('Theme changed to:', theme);
});
```

### 4.2 样式应用

```html
<div class="cognilink-card">
  <button class="cognilink-button">点击按钮</button>
  <input class="cognilink-input" type="text" placeholder="输入内容" />
</div>
```

## 5. 注意事项

1. 主题变量命名以 `cognilink-` 为前缀，避免与 Obsidian 变量冲突
2. 使用 CSS 变量时注意浏览器兼容性
3. 响应式布局断点统一使用预定义变量
4. 动画时长应适中，避免影响用户体验
