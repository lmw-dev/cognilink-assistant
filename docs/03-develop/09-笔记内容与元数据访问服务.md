# 笔记内容与元数据访问服务

## 技术实现方案

### 1. 服务封装
- 封装 Vault/MetadataCache API，支持按路径、标签、关键词等多维度检索。
- 提供统一服务接口（如 NoteService），便于 UI/AI 层调用。
- 支持异步批量读取，优化大库性能。

### 2. 元数据结构化访问
- 支持 frontmatter、标签、内部链接、YAML 等元数据解析。
- 提供类型安全的数据结构（TypeScript interface/type）。

### 3. 性能优化
- 批量操作采用异步并发，避免阻塞主线程。
- 可选缓存机制，减少重复读取。

### 4. 单元测试
- 使用 Jest 对服务层方法进行测试。
- Mock Obsidian Vault/MetadataCache，验证检索与解析逻辑。
