# 聊天侧边栏 UI 基础

## 技术实现方案

### 1. 侧边栏视图注册
- 使用 Obsidian Workspace API 注册自定义视图（如 SidebarView）。
- 视图类型常量定义，便于后续扩展。

### 2. 聊天输入与消息展示
- 输入区支持 Markdown，支持 Enter 提交、Shift+Enter 换行。
- 消息区支持 Markdown 渲染、滚动、区分用户/AI 消息。
- 结构化 React/Svelte 组件，推荐使用 React（如 obsidian-dataview、obsidian-kanban 等插件实践）。

### 3. 组件解耦
- UI 组件与服务层（如消息管理、AI 调用）解耦，采用 props/context 传递。
- 便于后续集成更多功能（如消息操作、上下文管理）。

### 4. 单元测试
- 使用 Jest + React Testing Library 编写 UI 组件测试。
- Mock Obsidian API，验证视图注册与 UI 交互。
