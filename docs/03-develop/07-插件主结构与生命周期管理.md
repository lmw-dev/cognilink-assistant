# 插件主结构与生命周期管理

## 技术实现方案

### 1. 插件主类与生命周期
- 继承 Obsidian 的 Plugin 类，主入口文件为 `main.ts`。
- 实现 `onload()` 方法：注册命令、视图、服务、设置面板等。
- 实现 `onunload()` 方法：释放所有注册资源，清理副作用。
- 遵循 Obsidian 官方插件开发文档的生命周期管理最佳实践。

### 2. 结构与扩展性
- 主类仅负责生命周期和资源注册，具体功能委托给服务类/组件。
- 采用依赖注入或服务定位器模式，便于后续扩展和测试。

### 3. 单元测试
- 使用 Jest/ts-jest 对主类生命周期流程进行测试。
- Mock Obsidian API，验证 onload/onunload 的资源注册与释放。

### 4. 参考代码结构
```typescript
import { Plugin } from 'obsidian';

export default class CogniLinkPlugin extends Plugin {
  async onload() {
    // 注册命令、视图、服务等
  }
  async onunload() {
    // 释放资源
  }
}
```
