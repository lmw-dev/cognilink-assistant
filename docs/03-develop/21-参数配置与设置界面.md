# 1. 需求分析

## 1.1 UI/UX 展示与交互

**目标：**
- 让用户在 Obsidian 插件界面中可视化查看 RAG 检索与内容整合结果。
- 支持分组展示、摘要、原文、来源编号与跳转。
- 支持一键插入到当前笔记或新建笔记。
- 支持交互式参数调整（如 topK、阈值、分组方式）。

**典型场景：**
- 用户输入检索主题，点击按钮后，界面展示分组结果（标签/主题），每组有摘要、原文、来源编号，底部有来源列表（可点击跳转）。
- 用户可调整参数（如 topK、阈值），点击“刷新”实时更新结果。
- 用户可一键插入整合内容到当前笔记或新建笔记。

---

## 1.2 参数配置与设置界面

**目标：**
- 在插件设置页（SettingsTab）中，允许用户自定义 RAG 检索相关参数。
- 支持参数包括：topK、相似度阈值、去重阈值、分组方式（标签/文件夹）、是否启用摘要、LLM prompt 模板等。
- 参数变更后自动保存并即时生效。

**典型场景：**
- 用户在设置页调整“检索数量(topK)”为 10，“相似度阈值”为 0.6，保存后主流程自动应用新参数。
- 用户可切换分组方式（如“按标签”或“按文件夹”）。

# 2. 技术实现方案与代码

## 2.1 UI/UX 展示与交互

### 方案建议

- 新建一个 RAG 结果展示面板（如 `RAGView.tsx` 或 `RAGResultModal.ts`）。
- 支持参数输入（input/slider）、刷新按钮、分组结果渲染、来源跳转、插入按钮。
- 可用 Obsidian Modal 或自定义 View（推荐 Modal，开发快，体验好）。

### 关键代码片段

#### 1. RAG 结果 Modal 组件（TypeScript）

```ts
import { Modal, App, Notice } from 'obsidian';
import { RAGService } from '../services/RAGService';

export class RAGResultModal extends Modal {
  private ragService: RAGService;
  private defaultQuery: string;
  private topK: number;
  private threshold: number;
  private dedupThreshold: number;

  constructor(app: App, ragService: RAGService, defaultQuery = '', topK = 8, threshold = 0.7, dedupThreshold = 0.98) {
    super(app);
    this.ragService = ragService;
    this.defaultQuery = defaultQuery;
    this.topK = topK;
    this.threshold = threshold;
    this.dedupThreshold = dedupThreshold;
  }

  async onOpen() {
    const { contentEl } = this;
    contentEl.empty();
    contentEl.createEl('h2', { text: '智能检索与内容整合' });

    // 参数输入
    const queryInput = contentEl.createEl('input', { type: 'text', value: this.defaultQuery, placeholder: '请输入检索主题' });
    const topKInput = contentEl.createEl('input', { type: 'number', value: String(this.topK), min: '1', max: '20', step: '1' });
    const thresholdInput = contentEl.createEl('input', { type: 'number', value: String(this.threshold), min: '0', max: '1', step: '0.01' });

    contentEl.createEl('label', { text: '检索数量(topK):' }).appendChild(topKInput);
    contentEl.createEl('label', { text: '相似度阈值:' }).appendChild(thresholdInput);

    const refreshBtn = contentEl.createEl('button', { text: '刷新结果', cls: 'mod-cta' });
    const insertBtn = contentEl.createEl('button', { text: '插入到当前笔记' });

    const resultDiv = contentEl.createDiv({ cls: 'rag-result-view' });

    const renderResult = async () => {
      resultDiv.empty();
      resultDiv.createEl('span', { text: '加载中...' });
      try {
        const markdown = await this.ragService.runRAGAndSummarize(
          queryInput.value,
          Number(topKInput.value),
          Number(thresholdInput.value),
          this.dedupThreshold
        );
        resultDiv.empty();
        // 用 Obsidian MarkdownRenderer 渲染
        // @ts-ignore
        await this.app.plugins.getPlugin('markdown').MarkdownRenderer.renderMarkdown(
          markdown,
          resultDiv,
          '',
          this
        );
      } catch (e) {
        resultDiv.empty();
        resultDiv.createEl('span', { text: '检索失败: ' + (e?.message || e) });
      }
    };

    refreshBtn.onclick = renderResult;
    insertBtn.onclick = async () => {
      const view = this.app.workspace.getActiveViewOfType(MarkdownView);
      if (view) {
        const content = resultDiv.innerText;
        view.editor.replaceSelection(content);
        new Notice('已插入到当前笔记');
      } else {
        new Notice('未找到可用的 Markdown 编辑器');
      }
    };

    contentEl.appendChild(refreshBtn);
    contentEl.appendChild(insertBtn);
    contentEl.appendChild(resultDiv);

    // 首次自动渲染
    await renderResult();
  }
}
```

## 2.2 参数配置与设置界面

### 方案建议

- 在 `SettingsTab` 里增加 RAG 相关参数设置项。
- 参数变更后保存到 `this.settings.rag`，主流程读取时自动应用。

### 关键代码片段

#### 1. 在 SettingsTab.ts 增加参数项

```ts
// 假设 this.plugin.settings.rag = { topK: 8, threshold: 0.7, dedupThreshold: 0.98 }
ragSection.addSetting(setting => {
  setting
    .setName('检索数量 (topK)')
    .setDesc('每次检索返回的笔记数量')
    .addText(text => text
      .setValue(String(this.plugin.settings.rag.topK))
      .onChange(async (value) => {
        this.plugin.settings.rag.topK = Number(value);
        await this.plugin.saveSettings();
      }));
});
ragSection.addSetting(setting => {
  setting
    .setName('相似度阈值')
    .setDesc('检索时的相似度阈值，0~1，越高越严格')
    .addText(text => text
      .setValue(String(this.plugin.settings.rag.threshold))
      .onChange(async (value) => {
        this.plugin.settings.rag.threshold = Number(value);
        await this.plugin.saveSettings();
      }));
});
ragSection.addSetting(setting => {
  setting
    .setName('去重阈值')
    .setDesc('内容去重时的相似度阈值，0~1，越高越严格')
    .addText(text => text
      .setValue(String(this.plugin.settings.rag.dedupThreshold))
      .onChange(async (value) => {
        this.plugin.settings.rag.dedupThreshold = Number(value);
        await this.plugin.saveSettings();
      }));
});
```

#### 2. 在 RAGService/主流程读取参数

```ts
const { topK, threshold, dedupThreshold } = this.plugin.settings.rag;
this.ragService.runRAGAndSummarize(query, topK, threshold, dedupThreshold);
```

# 3. 如何在 Obsidian 中测试

1. **设置参数**  
   - 打开插件设置页，调整“检索数量”、“相似度阈值”、“去重阈值”等参数，保存。

2. **使用命令面板**  
   - 按 `Ctrl+P`，输入“智能检索与内容整合”，回车弹出 RAG 结果 Modal。
   - 输入检索主题，调整参数，点击“刷新结果”。
   - 检查分组、摘要、归因、来源跳转等 UI 效果。

3. **插入内容**  
   - 在 Modal 里点击“插入到当前笔记”，检查内容是否正确插入。

4. **调试参数生效**  
   - 多次调整设置页参数，重复检索，观察结果变化。
