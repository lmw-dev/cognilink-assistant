# 笔记元数据服务（NoteMetaService）开发与测试说明

## 1. 功能概述
NoteMetaService 封装了 Obsidian Vault/MetadataCache API，支持批量读取笔记的 frontmatter、标签、内部链接等元数据，提供类型安全的结构化访问接口。

## 2. 主要接口
- `getNoteMeta(file: TFile): Promise<NoteMeta>`
  - 解析单个笔记的 frontmatter、tags、links。
- `getAllNotesMeta(): Promise<NoteMeta[]>`
  - 批量获取所有 Markdown 文件的元数据。
- `searchNotesByTag(tag: string): Promise<NoteMeta[]>`
  - 按标签检索笔记。
- `searchNotesByLink(target: string): Promise<NoteMeta[]>`
  - 按内部链接检索笔记。

## 3. 类型定义
```typescript
export interface NoteMeta {
  path: string;
  title: string;
  frontmatter: Record<string, any>;
  tags: string[];
  links: string[];
}
```

- 在 main.ts 注册 `test-note-meta` 命令，可在命令面板运行，Notice 提示笔记数量，Console 输出详细结构。
- 如命令未显示，优先排查插件加载、缓存、目录结构等问题。

## 6. 典型用法
```typescript
const service = new NoteMetaService(app);
const notes = await service.getAllNotesMeta();
const aiNotes = notes.filter(note => note.tags.includes('#AI'));
```
