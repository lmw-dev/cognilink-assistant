## 🚀 快速验收测试

### 方法1：使用内置验收测试命令 ⭐ **推荐**

1. **构建并部署插件**
   ```bash
   npm run build
   npm run deploy
   ```

2. **在Obsidian中运行验收测试**
   - 打开Obsidian
   - 按 `Ctrl+Shift+P` (Windows/Linux) 或 `Cmd+Shift+P` (Mac) 打开命令面板
   - 搜索并执行：`TOM-107 平台模板系统验收测试`
   - 查看通知和控制台输出

3. **查看测试结果**
   - Obsidian会显示测试结果通知
   - 按 `Ctrl+Shift+I` (Windows/Linux) 或 `Cmd+Option+I` (Mac) 打开开发者工具查看详细日志
   - 控制台会显示每个平台的详细测试结果

### 方法2：控制台手动测试（备用方法）

如果方法1不可用，可以在开发者控制台中手动运行：

```javascript
// 获取插件实例
const plugin = window.plugin;

// 运行验收测试
await plugin.runTOM107AcceptanceTest();
```

## 🐛 常见问题

### Q1: 控制台报错 "Cannot import module"
**解决**: 确保已运行 `npm run build` 构建项目

### Q2: 模板渲染失败
**解决**: 检查上下文数据是否完整，topic和context不能为空

### Q3: 平台特色检查失败
**解决**: 这是正常的，模板只是提供框架，实际内容由AI生成

### Q4: 性能测试超时
**解决**: 检查缓存是否正常工作，清理缓存后重试
