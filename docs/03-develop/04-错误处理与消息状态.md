# 错误处理与消息状态实现文档

## 一、错误处理系统 (TOM-22)

### 1.1 功能概述

实现了一个集中式的错误处理系统，用于统一管理和展示各类错误信息。

### 1.2 核心组件

#### ErrorHandler 类 (src/components/ErrorHandler.tsx)
- 采用单例模式确保全局唯一实例
- 支持不同类型的错误处理
- 集成重试机制
- 提供友好的用户提示

### 1.3 错误类型

```typescript
class AIServiceError extends Error {
  constructor(message: string, public code: string)
}

class ConfigurationError extends AIServiceError
class APIError extends AIServiceError
class NetworkError extends AIServiceError
```

### 1.4 主要功能

1. 错误处理
   - 配置错误 (⚙️, 10秒)
   - API错误 (🔌, 带重试)
   - 网络错误 (🌐, 带重试)
   - 验证错误 (⚠️)
   - 未知错误 (❌)

2. 通知类型
   - 成功提示 (✅)
   - 信息提示 (ℹ️)
   - 警告提示 (⚠️)

3. 重试机制
   - 支持可恢复错误的重试
   - 重试按钮集成
   - 重试状态管理

### 1.5 使用示例

```typescript
const errorHandler = ErrorHandler.getInstance();

// 处理错误
errorHandler.handleError(error, retryCallback);

// 显示成功消息
errorHandler.showSuccess('操作成功');

// 显示信息
errorHandler.showInfo('正在处理');

// 显示警告
errorHandler.showWarning('请注意');
```

## 二、消息状态系统 (TOM-21)

### 2.1 功能概述

实现了消息的各种状态显示和加载效果，提供流畅的用户体验。

### 2.2 核心组件

#### MessageStatus 组件 (src/components/MessageStatus.tsx)
- 状态展示组件
- 加载动画
- 进度指示器

### 2.3 状态类型

```typescript
enum MessageState {
  SENDING = 'sending',
  SUCCESS = 'success',
  ERROR = 'error',
  LOADING = 'loading',
  TYPING = 'typing',
}
```

### 2.4 主要功能

1. 消息状态
   - 发送中 (📤 + 加载动画)
   - 发送成功 (✅)
   - 发送失败 (❌ + 重试按钮)
   - 加载中 (⏳ + 进度条)
   - 正在输入 (✍️ + 加载动画)

2. 动画效果
   - 加载点动画
   - 进度条动画
   - 状态转换动画
   - 重试按钮悬停效果

### 2.5 使用示例

```typescript
// 发送状态
<MessageStatus state={MessageState.SENDING} />

// 成功状态（自定义消息）
<MessageStatus 
  state={MessageState.SUCCESS}
  message="消息已发送"
/>

// 错误状态（带重试）
<MessageStatus
  state={MessageState.ERROR}
  message="发送失败"
  onRetry={() => handleRetry()}
/>

// 加载状态（带进度）
<MessageStatus
  state={MessageState.LOADING}
  message="正在加载"
  progress={75}
/>
```

### 2.6 样式定制

所有样式都使用 CSS 变量，支持主题适配：
- `--background-secondary`
- `--background-modifier-border`
- `--background-modifier-success`
- `--background-modifier-error`
- `--text-success`
- `--text-error`
- `--interactive-accent`
- `--text-on-accent`
