# 安全与配置管理

## 技术实现方案

### 1. 设置面板
- 使用 Obsidian 的 SettingTab API 创建插件专属设置面板。
- 支持 API 密钥、模型选择、上下文管理等基础配置项。
- 配置项类型安全，支持校验与默认值。

### 2. API 密钥安全存储
- 密钥加密存储于 Obsidian 插件本地配置（如 .obsidian/plugins/cognilink-assistant/settings.json）。
- 绝不明文存储于代码或日志。
- 读取/写入均需加密/解密处理（可用简单对称加密或平台安全 API）。

### 3. 配置管理服务
- 封装 ConfigService，统一管理配置项的读写、校验、默认值。
- 提供类型安全的配置接口。

### 4. 单元测试
- 使用 Jest 测试配置项读写、加密解密、校验逻辑。
- Mock Obsidian SettingTab/存储 API。

### 5. 参考代码结构
```typescript
import { PluginSettingTab, App, Setting } from 'obsidian';

export interface PluginSettings {
  apiKey: string;
  model: string;
  // ...其他配置项
}

export class CogniLinkSettingTab extends PluginSettingTab {
  constructor(app: App, plugin: any) {
    super(app, plugin);
  }
  display() {
    // 渲染设置面板
    new Setting(this.containerEl)
      .setName('API 密钥')
      .addText(text => text
        .setValue(this.plugin.settings.apiKey)
        .onChange(async (value) => {
          this.plugin.settings.apiKey = value;
          await this.plugin.saveSettings();
        }));
  }
}
```
