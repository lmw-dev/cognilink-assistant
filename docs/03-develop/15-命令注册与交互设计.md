# 命令注册与交互设计说明

## 1. 设计目标
- 通过 Obsidian 插件 API 注册核心命令，提升插件可用性和交互性。
- 命令与 UI/服务层解耦，便于扩展和维护。

## 2. 主要命令列表
- `start-new-chat`：新建聊天
- `clear-chat-history`：清空聊天记录
- `copy-last-message`：复制最后一条消息
- `check-originality`：检查原创性（占位，后续实现）
- `test-note-meta`：测试笔记元数据解析

## 3. 注册方式
- 在插件 onload 生命周期中调用 `this.addCommand` 注册命令。
- 命令 id、name、callback 明确分离，便于维护。
- 命令注册与命令实现分离，回调仅负责调度服务层方法。

## 4. 典型代码结构
```typescript
this.addCommand({
  id: 'start-new-chat',
  name: '新建聊天',
  callback: () => {
    this.chatManager?.startNewChat?.();
  }
});
```

## 5. 单元测试
- Mock Obsidian API，验证命令注册与回调逻辑。
- 重点测试命令是否被注册、回调是否被正确调用。

## 6. 扩展建议
- 新增命令时，建议先在服务层实现功能，再注册命令。
- 命令注册应有日志输出，便于调试。
- 支持快捷键配置和命令分组。
