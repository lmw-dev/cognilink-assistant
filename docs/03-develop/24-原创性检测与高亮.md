## 1. 新增原创性检测主流程

### 需求详述
- **目标**：对生成的文档内容进行原创性检测，自动分析每个段落与库内所有笔记的相似度，输出每段的相似度分数及最相似笔记信息。
- **粒度**：以“段落”为单位（可配置为句子）。
- **输出**：每段内容、相似度分数、最相似笔记标题与路径。

### 技术实现
- **服务文件**：`src/services/OriginalityService.ts`
- **核心方法**：`checkOriginality(content: string, threshold: number): Promise<OriginalityResult[]>`
  - 1. 按段落（或句子）切分 content。
  - 2. 遍历每段，调用 EmbeddingService 生成 embedding。
  - 3. 与库内所有笔记（或 embedding 索引）计算相似度，找出最大相似度及其来源。
  - 4. 返回每段的检测结果（含文本、相似度、最相似笔记标题/路径）。
- **性能优化**：embedding 计算和相似度比对可并发处理，避免阻塞 UI。

#### 数据结构示例
```ts
export interface OriginalityResult {
  text: string;
  index: number;
  similarity: number;
  sourceTitle: string;
  sourcePath: string;
}
```

## 2. 在 PreviewModal 中集成检测与高亮

### 需求详述
- **目标**：在生成文档预览弹窗中，自动展示原创性检测结果，对疑似重复段落高亮，并显示相似度和来源。
- **交互**：
  - 检测后，高相似度段落高亮（如背景色/边框）。
  - 鼠标悬停显示相似度分数和最相似笔记信息。
  - 支持“重新检测”按钮，允许用户再次检测。
  - 支持“只看高亮”开关，便于聚焦问题段落。

### 技术实现
- **在 PreviewModal 中**：
  - 生成文档后，自动调用 `OriginalityService.checkOriginality`。
  - 渲染为段落列表，高相似度段落加高亮 class。
  - 悬停显示 tooltip，内容为“相似度：xx%，最相似笔记：xxx”。
  - “重新检测”按钮重新触发检测。
  - “只看高亮”切换只显示疑似重复段落。
- **高亮样式**：可用 CSS class（如 `.originality-duplicate`），颜色/边框可配置。

## Obsidian 插件测试方法

### 1. 功能测试
- 生成原创文档后，自动弹出预览，**每段内容下方应显示原创性检测高亮**。
- **高亮段落悬停**，应显示相似度分数和最相似笔记标题。
- 修改文档内容，点击“重新检测”，高亮和提示应实时更新。
- 切换“只看高亮”，只显示疑似重复段落。

### 2. 设置测试
- 在设置页调整相似度阈值，保存后重新检测，**高亮数量应随阈值变化**。
- 切换检测粒度，验证段落/句子级别检测效果。

### 3. 性能与异常测试
- 大文档检测时，UI 不应卡死，检测进度可有 loading 提示。
- 无相似内容时，无高亮，提示“全部原创”。
- 断网/embedding 失败时，显示错误提示。

### 4. 兼容性测试
- 主题切换下高亮样式正常。
- 插件与 Obsidian 其它输入/编辑功能无冲突。
