# 1. 技术实现方案

## 目标
- 输入 query（如“cursor 流程”），返回与之最相关的本地笔记（topK，支持阈值）。
- 支持向量语义检索，优先用本地嵌入（embeddings.json）。
- 支持关键词检索兜底（如无嵌入或相关性低时）。

## 技术要点
- **Query 向量化**：将 query 文本转为 embedding（用 OpenAI embedding API）。
- **相似度计算**：用余弦相似度（cosine similarity）比较 query 向量与每个笔记 embedding。
- **排序与筛选**：按相似度降序排序，支持 topK 和阈值（如 0.75）。
- **兜底关键词检索**：如无嵌入或相关性低，fallback 到关键词匹配。

# 2. 代码实现

假设你已有 `EmbeddingService`，本地嵌入数据结构如下：

```ts
interface NoteEmbedding {
  path: string;
  embedding: number[];
  updated: number;
  title: string;
  tags: string[];
}
type EmbeddingIndex = Record<string, NoteEmbedding>;
```

## 2.1 余弦相似度函数

```ts
function cosineSimilarity(a: number[], b: number[]): number {
  const dot = a.reduce((sum, ai, i) => sum + ai * b[i], 0);
  const normA = Math.sqrt(a.reduce((sum, ai) => sum + ai * ai, 0));
  const normB = Math.sqrt(b.reduce((sum, bi) => sum + bi * bi, 0));
  return dot / (normA * normB);
}
```

## 2.2 EmbeddingService.findRelevantNotes

```ts
import { request } from 'obsidian';

export class EmbeddingService {
  // ... 省略构造与本地加载

  /**
   * 语义检索与排序
   * @param query 用户输入
   * @param topK 返回前K条
   * @param threshold 相似度阈值
   */
  async findRelevantNotes(query: string, topK = 5, threshold = 0.75): Promise<NoteEmbedding[]> {
    // 1. 加载本地嵌入
    const embeddings: EmbeddingIndex = await this.loadEmbeddingsIndex();
    const notes = Object.values(embeddings);
    if (!notes.length) return [];

    // 2. query 向量化
    const queryEmbedding = await this.generateEmbedding(query);

    // 3. 计算相似度
    const scored = notes.map(note => ({
      ...note,
      score: cosineSimilarity(queryEmbedding, note.embedding)
    }));

    // 4. 排序与筛选
    const sorted = scored
      .filter(n => n.score >= threshold)
      .sort((a, b) => b.score - a.score)
      .slice(0, topK);

    // 5. 兜底关键词检索
    if (sorted.length === 0) {
      // 简单关键词兜底
      const keywordHits = notes.filter(n =>
        n.title.includes(query) ||
        (n.tags && n.tags.some(tag => query.includes(tag)))
      );
      return keywordHits.slice(0, topK);
    }

    return sorted;
  }

  // 生成 query 的 embedding
  async generateEmbedding(text: string): Promise<number[]> {
    // 推荐直接复用 AIService.generateEmbeddings
    // 这里以 OpenAI API 为例
    const apiKey = this.plugin.settings.ai.openAIApiKey;
    const endpoint = 'https://api.openai.com/v1/embeddings';
    const res = await request({
      url: endpoint,
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        model: 'text-embedding-ada-002',
        input: text
      })
    });
    const data = JSON.parse(res);
    return data.data[0].embedding;
  }

  // 加载本地嵌入索引
  async loadEmbeddingsIndex(): Promise<EmbeddingIndex> {
    // 省略，假设已实现
  }
}
```

## 3.1 手动测试
