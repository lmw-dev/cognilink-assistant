# 消息状态与加载效果实现

## 1. 概述

为了提供更好的用户体验，我们实现了完整的消息状态管理和加载效果系统。主要包括消息状态管理、加载动画、打字机效果等。

## 2. 主要实现

### 2.1 消息状态管理器 (MessageStateManager)

消息状态管理器采用观察者模式，管理三种不同类型的状态：

1. 消息状态（发送中、已发送、失败等）
2. 加载状态（进度条）
3. 打字状态（打字机效果）

```typescript
class MessageStateManager {
  // 状态管理
  private messageState: MessageState = { status: 'sent' };
  private loadingState: MessageLoadingState = { isLoading: false, progress: 0, total: 0 };
  private typingState: MessageTypingState = {
    isTyping: false,
    text: '',
    displayedText: '',
    typingSpeed: 50,
  };

  // 观察者列表
  private messageObservers: MessageStateObserver[] = [];
  private loadingObservers: LoadingStateObserver[] = [];
  private typingObservers: TypingStateObserver[] = [];
}
```

### 2.2 状态类型定义

```typescript
export type MessageStatus = 'sending' | 'sent' | 'failed' | 'loading' | 'typing';

export interface MessageState {
  status: MessageStatus;
  error?: Error;
  progress?: number;
  retryCount?: number;
}

export interface MessageLoadingState {
  isLoading: boolean;
  progress: number;
  total: number;
}

export interface MessageTypingState {
  isTyping: boolean;
  text: string;
  displayedText: string;
  typingSpeed: number;
}
```

### 2.3 状态展示组件

状态展示组件根据不同状态显示相应的 UI：

```typescript
export const MessageStatus: React.FC<MessageStatusProps> = ({
  messageId,
  stateManager,
  onRetry,
}) => {
  // ... 状态订阅逻辑 ...

  const renderStatus = () => {
    switch (messageState.status) {
      case 'sending':
        return <LoadingDotsAnimation />;
      case 'failed':
        return <ErrorWithRetry onRetry={onRetry} />;
      case 'loading':
        return <ProgressBar progress={loadingState.progress} total={loadingState.total} />;
      case 'typing':
        return <TypingIndicator text={typingState.displayedText} />;
      default:
        return null;
    }
  };
};
```

## 3. 特性

1. 消息状态
   - 发送中状态（带加载动画）
   - 发送成功状态
   - 发送失败状态（带重试按钮）
   - 加载历史状态（带进度条）
   - 正在输入状态（打字机效果）

2. 动画效果
   - 加载点动画
   - 进度条动画
   - 打字机效果
   - 状态转换动画

3. 交互设计
   - 失败重试机制
   - 进度反馈
   - 状态提示
   - 平滑过渡

## 4. 使用示例

### 4.1 基本使用

```typescript
const messageStateManager = new MessageStateManager();

// 设置发送状态
messageStateManager.setMessageStatus('sending');

// 更新加载进度
messageStateManager.startLoading(100);
messageStateManager.updateProgress(50);

// 开始打字效果
messageStateManager.startTyping('这是一段打字机效果的文本');
```

### 4.2 组件使用

```tsx
<MessageStatus
  messageId="msg-1"
  stateManager={messageStateManager}
  onRetry={() => handleRetry()}
/>
```

## 5. 注意事项

1. 状态转换要考虑所有可能的状态组合
2. 动画效果要适度，避免过于花哨
3. 错误处理要完善，提供重试机制
4. 性能优化，避免不必要的重渲染
5. 确保状态管理的内存释放
