# 设置面板组件实现

## 1. 概述

设置面板组件用于配置插件的各项功能，包括 AI 服务设置、界面选项和快捷键配置。使用 Obsidian 的设置 API 实现，确保与 Obsidian 的设置面板风格保持一致。

## 2. 主要实现

### 2.1 设置类型定义

```typescript
export type AIProvider = 'openai' | 'anthropic' | 'local';
export type AIModel = 'gpt-4' | 'gpt-3.5-turbo' | 'claude-2' | 'claude-instant';

export interface AISettings {
  provider: AIProvider;
  openAIApiKey: string;
  anthropicApiKey: string;
  model: AIModel;
  temperature: number;
  maxTokens: number;
  defaultSystemPrompt: string;
}

export interface PluginSettings {
  ui: UISettings;
  ai: AISettings;
  shortcuts: {
    toggleChat: string;
    newChat: string;
    focusInput: string;
  };
}
```

### 2.2 设置管理器

设置管理器 (`SettingsManager`) 负责：
- 加载和保存设置
- 更新设置并同步到插件实例
- 验证设置有效性
- 管理设置变更事件
- 导入导出设置

关键实现：
```typescript
export class SettingsManager extends EventEmitter {
  async updateAISettings(aiSettings: Partial<PluginSettings['ai']>): Promise<void> {
    const updatedAISettings = {
      ...this.settings.ai,
      ...aiSettings,
    };
    await this.updateSettings({
      ai: updatedAISettings,
    });
  }
}
```

### 2.3 设置存储

设置存储 (`SettingsStorage`) 使用 Obsidian 的数据 API：
```typescript
export class SettingsStorage {
  async loadSettings(): Promise<PluginSettings> {
    const settings = await this.plugin.loadData();
    return settings ? { ...DEFAULT_SETTINGS, ...settings } : { ...DEFAULT_SETTINGS };
  }

  async saveSettings(settings: PluginSettings): Promise<void> {
    await this.plugin.saveData(settings);
  }
}
```

### 2.4 设置面板组件

设置面板组件 (`SettingsTab`) 实现：
- AI 服务配置
  - 提供商选择（OpenAI/Anthropic/本地）
  - API 密钥管理
  - 模型选择
  - 参数调整
- 界面设置
  - 主题选择
  - 字体大小
  - 消息间距
  - 时间戳显示
- 快捷键配置

## 3. 特性

1. 动态设置项
   - 根据 AI 提供商显示/隐藏相关设置
   - 自动更新模型选项
   - 实时验证输入

2. 设置同步
   - 实时保存到 Obsidian 数据存储
   - 自动同步到插件实例
   - 触发设置变更事件

3. 数据验证
   - API 密钥有效性检查
   - 设置值范围验证
   - 快捷键冲突检测

## 4. 注意事项

1. 设置更新
   - 确保设置更新时同步到插件实例
   - 使用深拷贝避免引用问题
   - 保持设置一致性

2. 错误处理
   - 加载失败时使用默认设置
   - 保存失败时提供错误提示
   - 验证失败时阻止无效更新

3. 性能优化
   - 避免频繁保存
   - 使用事件节流
   - 优化渲染逻辑

## 5. 使用示例

```typescript
// 初始化设置管理器
const storage = new SettingsStorage(this);
this.settingsManager = new SettingsManager(this.app, this, storage);
await this.settingsManager.loadSettings();

// 监听设置变更
this.settingsManager.addSettingsChangeListener((settings) => {
  // 处理设置变更
});

// 更新 AI 设置
await this.settingsManager.updateAISettings({
  provider: 'openai',
  model: 'gpt-4',
});
```
