# Obsidian 插件项目结构

## 1. 项目结构

```
cognilink-assistant/
├── src/                      # 源代码目录
│   ├── main.ts              # 插件入口文件
│   ├── services/            # 服务层（AI、数据处理等）
│   ├── components/          # UI 组件
│   ├── types/               # TypeScript 类型定义
│   ├── constants/           # 常量定义
│   ├── hooks/               # React Hooks
│   └── utils/               # 工具函数
├── dist/                    # 构建输出目录
├── __mocks__/              # Jest 模拟文件
├── tests/                   # 测试文件目录
├── docs/                    # 项目文档
├── styles.css              # 插件样式
├── manifest.json           # 插件清单
├── package.json            # 项目配置
└── tsconfig.json           # TypeScript 配置
```

## 2. 核心配置文件

### 2.1 TypeScript 配置 (tsconfig.json)

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "inlineSourceMap": true,
    "inlineSources": true,
    "module": "ESNext",
    "target": "ES6",
    "allowJs": true,
    "noImplicitAny": true,
    "moduleResolution": "node",
    "importHelpers": true,
    "isolatedModules": true,
    "strictNullChecks": true,
    "lib": ["DOM", "ES5", "ES6", "ES7", "ES2021"],
    "jsx": "react",
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src/**/*.ts", "src/**/*.tsx"]
}
```

主要特点：
- 使用 ES6 作为目标
- 启用严格的类型检查
- 支持 React JSX
- 配置路径别名 @/* -> src/*
- 支持源码映射

### 2.2 构建配置 (esbuild.config.mjs)

使用 esbuild 进行构建，主要配置：
- 入口文件：src/main.ts
- 输出文件：dist/main.js
- 格式：CommonJS
- 目标：ES2018
- 外部依赖：obsidian 及相关库
- 开发模式支持监听和源码映射

## 3. 开发工具配置

### 3.1 ESLint 配置

- 使用 TypeScript ESLint 解析器
- 集成 Prettier
- 配置代码规范规则

### 3.2 Prettier 配置

- 使用单引号
- 使用 2 空格缩进
- 最大行长度 100
- 启用尾随逗号

### 3.3 Jest 测试配置

- 使用 ts-jest 预设
- 配置 jsdom 测试环境
- 模拟 Obsidian API
- 支持测试覆盖率报告

## 4. 目录说明

### 4.1 src 目录结构

- **main.ts**: 插件入口文件，包含插件类定义和初始化逻辑
- **services/**: 服务层实现
  - AI 服务（与 LLM API 交互）
  - 数据服务（Obsidian 数据访问）
  - 嵌入服务（向量存储和检索）
- **components/**: React/Svelte UI 组件
  - 聊天界面
  - 设置面板
  - 通用组件
- **types/**: TypeScript 类型定义
  - API 响应类型
  - 配置类型
  - 通用类型
- **constants/**: 常量定义
  - 默认设置
  - API 端点
  - 提示模板
- **hooks/**: React 自定义 Hooks
- **utils/**: 工具函数
  - API 调用封装
  - 数据处理
  - 工具函数

### 4.2 测试目录结构

- **tests/**: 测试文件
  - 单元测试
  - 集成测试
  - 测试工具和辅助函数

### 4.3 文档目录结构

- **docs/**: 项目文档
  - 开发指南
  - API 文档
  - 架构文档

## 5. 构建和开发命令

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 运行测试
npm test

# 运行测试（监听模式）
npm run test:watch

# 代码检查
npm run lint

# 格式化代码
npm run format
```
