# TOM-121: 平台模板管理 UI 开发与测试文档

**任务ID**: TOM-121
**模块**: Prompt系统 - 平台模板管理 UI
**负责人**: Cursor AI
**完成日期**: 2025年06月02日

---

## 1. 任务目标与背景

- 实现多平台 Prompt 模板的统一管理 UI，支持增删改查、预览、导入导出、批量操作、分层编辑等功能。
- 保证类型安全、可扩展性和高测试覆盖率，支撑后续内容生成、质量评估等主流程。
- 适配小红书、头条号、微信公众号、个人博客、Twitter、知乎、抖音、LinkedIn 等主流平台。

---

## 2. 主要实现内容

### 2.1 UI 功能
- 平台模板管理主界面（`PlatformTemplateManager.tsx`），支持：
  - 模板列表（内置+自定义）、平台/分类筛选、搜索、批量选择
  - 新建、编辑、删除、设为默认、导入、导出、复制等操作
  - 分层编辑（系统/任务/上下文/输出）、变量插入、示例管理
  - 模板预览、质量规则、反AI痕迹配置
  - 友好的空状态、加载、错误提示
- 导入导出支持 JSON 格式，自动去重、冲突重命名、字段校验
- 支持批量操作（多选删除/导出/复制），提升管理效率
- 分层编辑器与主流程解耦，便于后续复用

### 2.2 类型安全与可扩展性
- 所有模板、平台、变量、规则等均有严格 TypeScript 类型定义（见 `src/types/prompt-advanced.ts`, `src/types/social-media.ts`）
- 支持平台扩展（`PlatformId` 可扩展）、模板分类、变量校验、质量规则自定义
- 内置模板与自定义模板分离，便于升级和用户个性化

### 2.3 单元测试与覆盖率
- 测试文件：`src/components/__tests__/PlatformTemplateManager.test.ts`
- 覆盖：
  - 模板增删改查、导入导出、批量操作、分层编辑、冲突处理、类型校验等核心逻辑
  - Mock Obsidian API、内置模板、深拷贝、确认弹窗等依赖
  - 边界与异常场景（如无模板、导入格式错误、字段缺失等）
- 目标覆盖率≥80%，实际已达高覆盖率

### 2.4 主要类型与数据结构
- `AdvancedPromptTemplate`：高级分层模板核心类型，支持分层、变量、示例、质量规则、反AI痕迹、元数据等
- `PlatformId`：平台标识符，支持主流社交平台扩展
- `PromptCategory`、`PromptVariable`、`QualityRule` 等类型，详见 `src/types/prompt-advanced.ts`
- 内置模板见 `src/config/advanced-platform-templates.ts`

---

## 3. 技术决策与挑战

- **类型安全优先**：所有数据流、状态、props、导入导出均强类型，避免 any/unknown
- **可扩展性**：平台、模板、变量、规则均可扩展，支持未来新平台和业务需求
- **UI/服务解耦**：UI 组件与模板存储、主流程解耦，便于单元测试和后续集成
- **异常处理**：导入导出、批量操作、保存等均有详细异常提示和日志
- **测试驱动**：先有类型和测试，再完善 UI 细节，保证主流程稳定

## 4. 单元测试与验收方法

### 4.1 单元测试
- 运行 `npm test`，确保 `PlatformTemplateManager.test.ts` 全部通过
- 重点测试点：
  - 初始化与状态同步
  - 模板增删改查、批量操作、导入导出
  - 类型校验、冲突处理、异常分支
  - 分层编辑、变量/示例/规则管理
- Mock Obsidian API、内置模板、深拷贝、确认弹窗等

### 4.2 端到端功能验收建议
- 在 Obsidian 插件设置页或主面板中，打开"平台模板管理"界面
- 验证：
  - 模板列表、平台/分类筛选、搜索、批量选择
  - 新建、编辑、删除、设为默认、导入、导出、复制等操作
  - 分层编辑、变量插入、示例管理、质量规则配置
  - 导入导出 JSON，冲突自动重命名、字段校验
  - 空状态、加载、错误提示
- 批量操作、分层编辑、导入导出等高频场景下无明显 bug
- 明暗主题、不同平台下 UI 兼容性良好
