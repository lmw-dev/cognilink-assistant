# 3. 内容去重、归类、摘要

## 需求分析
- **目标**：对检索到的相关笔记内容，去除重复、按标签/主题分组，并为每组生成简明摘要。
- **价值**：提升检索结果的可读性和信息密度，减少冗余，便于后续内容整合。
- **场景**：用户检索“AI 伦理”，返回多篇相关笔记，自动去重、分组、摘要，便于快速理解和后续处理。

## 技术实现方案
- **去重**：基于内容全等或 embedding 余弦相似度（如 >0.98）去重。
- **归类**：优先按标签分组，无标签归为“未分组”；可扩展按主题/文件夹分组。
- **摘要**：对每组内容用 LLM（如 OpenAI）生成一句话摘要。
- **实现**：已在 `RAGService` 中实现 `deduplicateNotes`、`groupNotesByTag`、`summarizeGroup`，主流程为 `runRAGPipeline`。

# 4. 归因机制

## 需求分析
- **目标**：为每段整合内容附上来源编号/链接，实现“可追溯”。
- **价值**：用户可一键跳转原笔记，保证内容可信、可复查。
- **场景**：整合输出“AI 伦理的核心问题有...【1】【2】”，底部列出来源笔记标题和链接。

## 技术实现方案
- **分组结果**中每条 `Note` 都包含 `link` 字段（如 `obsidian://open?...`），可直接用于归因。
- **内容整合时**，为每段内容附上来源编号（如【1】、【2】），并在底部生成来源列表。
- **UI 层**可渲染为可点击的链接，或在 markdown 中插入 `[1](obsidian://open?...)`。
- **实现建议**：在内容整合函数中，遍历每组 notes，生成编号和链接映射，组装归因文本。

# 5. 内容整合与 LLM 生成

## 需求分析
- **目标**：将分组、归因后的内容，传递给 LLM，生成结构化、归纳总结的最终内容。
- **价值**：自动输出高质量的知识整合笔记，便于插入到 Obsidian。
- **场景**：用户输入主题，插件自动检索、整合、归因、总结，输出一份可直接插入的 markdown。

## 技术实现方案
- **组装上下文**：将每组内容（含编号、摘要、原文）拼接为 prompt，附带来源编号。
- **LLM 调用**：用 AIService.sendMessage 发送 prompt，如“请基于以下资料，按主题分段整合并归纳总结，内容后附来源编号：\n...”
- **结果处理**：LLM 返回 markdown 格式内容，插件可直接插入到当前笔记或新建笔记。
- **实现建议**：新增 `buildContextWithCitations` 工具函数，组装带归因的上下文，主流程调用 LLM 生成最终内容。

# Obsidian 插件中如何测试这三个功能

## 1. 内容去重、归类、摘要

**测试方法：**
- 在控制台或命令面板调用：
  ```js
  const ragService = new RAGService(plugin.embeddingService, plugin.aiService);
  ragService.runRAGPipeline('AI 伦理', 8, 0.7, 0.98).then(res => console.log(res));
  ```
- 检查输出：应为按标签分组的数组，每组有 `tag`、`summary`、`notes` 字段，notes 内无重复内容。

## 2. 归因机制

**测试方法：**
- 用上一步的分组结果，手动或用工具函数组装归因文本：
  ```js
  function buildContextWithCitations(groups) {
    let context = '';
    let sources = [];
    let idx = 1;
    for (const group of groups) {
      context += `## ${group.tag}\n摘要：${group.summary}\n`;
      for (const note of group.notes) {
        context += `【${idx}】${note.content}\n`;
        sources.push(`[${idx}] ${note.title} (${note.link})`);
        idx++;
      }
    }
    context += '\n来源列表：\n' + sources.join('\n');
    return context;
  }
  // 用法
  ragService.runRAGPipeline('AI 伦理', 8, 0.7, 0.98).then(groups => {
    const context = buildContextWithCitations(groups);
    console.log(context);
  });
  ```
- 检查输出：每段内容后有编号，底部有来源列表和可点击链接。

## 3. 内容整合与 LLM 生成

**测试方法：**
- 用上一步生成的 context，调用 LLM 生成最终内容：
  ```js
  ragService.runRAGPipeline('AI 伦理', 8, 0.7, 0.98).then(async groups => {
    const context = buildContextWithCitations(groups);
    const res = await plugin.aiService.sendMessage({
      role: 'user',
      content: `请基于以下资料，按主题分段整合并归纳总结，内容后附来源编号：\n${context}`,
      timestamp: Date.now(),
      id: Date.now().toString(),
    });
    console.log(res.content);
  });
  ```
- 检查输出：应为结构化的 markdown，总结内容后附来源编号，可直接插入笔记。
