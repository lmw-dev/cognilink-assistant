你的问题非常明确：  
- 你用 RAG 检索（见 @27-advanced-rag-retriever.md）生成文章，但结果经常偏离目标，甚至内容概念都不对。  
- 你不想大动干戈，只想要**立竿见影、简单有效**的方案，优先考虑 prompt、RAG 检索参数、参考文档范围的调整。  
- 你要一个**可落地、可操作**的方案。

## 1. 问题本质分析

- RAG 检索出来的内容和目标不符，常见原因：
  1. **Prompt 不够明确/具体**，AI 不知道你真正想要什么。
  2. **RAG 检索参数不合适**，召回了不相关或噪声文档。
  3. **参考文档范围太宽/太杂**，导致检索结果偏离主题。
  4. **AI 没有被“约束”输出格式和内容风格**，自由发挥导致偏题。

## 2. 立竿见影的可落地方案

### 步骤一：优化 Prompt（最直接有效）

#### 2.1 明确你的目标和角色
- 在 prompt 里**直接写明你要的内容类型、风格、重点**，并给 AI 设定角色。
- 示例（以内容分析为例）：

```text
你是一位专业的内容分析师。请基于下方参考资料，生成一篇关于“AI伦理”的科普文章，要求：
- 只引用参考资料中的内容，不要编造
- 结构清晰，包含引言、主要观点、结论
- 语言简明，适合大众读者
- 重点突出“AI伦理的主要争议点”
- 输出格式为 Markdown
```

#### 2.2 明确引用范围
- 在 prompt 里加一句：“只允许引用下方检索到的文档内容，不要发挥想象。”

#### 2.3 给出示例（Few-shot）
- 如果有理想输出，直接贴一段作为示例。

---

### 步骤二：收紧 RAG 检索参数

#### 2.4 提高相关性阈值
- 在 `retrieve` 方法参数里，把 `minScore` 提高（如 0.8 或 0.85），减少无关文档。

#### 2.5 减少 topK 数量
- 只取最相关的 3-5 篇文档，避免噪声。

#### 2.6 关键词权重适当调高
- 如果你的目标很明确，适当提高 `keywordWeight`，让关键词匹配更重要。

---

### 步骤三：限定参考文档范围

#### 2.7 只检索与你主题最相关的文档
- 可以通过 tag、文件夹、标题等过滤，只让 RAG 检索“AI伦理”相关的文档。

#### 2.8 手动指定参考文档（如果自动检索不准）
- 允许用户手动勾选参考文档，或在 prompt 里直接贴入最关键的内容。

---

### 步骤四：输出格式和内容约束

#### 2.9 明确要求输出格式
- 在 prompt 里写明：“请以 Markdown 格式输出，分为引言、主体、结论三部分。”

#### 2.10 禁止编造
- 明确要求：“如无相关内容，请直接说明‘未找到相关信息’，不要编造。”

---

## 3. 可落地的操作清单

1. **调整 Prompt**  
   - 明确目标、角色、引用范围、输出格式
   - 示例 prompt 如上

2. **调整 RAG 检索参数**  
   - `minScore` 提高到 0.8-0.85
   - `topK` 降到 3-5
   - `keywordWeight` 适当提高（如 0.5）

3. **限定参考文档范围**  
   - 只检索相关 tag/文件夹/标题
   - 或手动指定参考文档

4. **测试效果**  
   - 先用一两个典型问题测试，观察输出是否明显改善

5. **如仍不理想**  
   - 进一步收紧检索范围
   - 或直接人工挑选参考内容

---

## 1. 现有产品形态分析

- **SettingsTab.tsx**  
  - 这是插件的“全局设置”页面，用户可以配置 AI Provider、模型、RAG 参数、Prompt 模板等。
  - 你已经有“Prompt 模板管理”区块，支持新增、编辑、删除、设为默认、恢复默认等操作。
  - 适合做**全局性、长期有效的 Prompt 优化和模板管理**。

- **SocialMediaGenerationModal.tsx**  
  - 这是“内容生成”功能的弹窗，用户在这里选择平台、主题、风格等，生成具体内容。
  - 这里的 prompt 主要是通过模板和参数动态组装，用户一般是“用”而不是“配” prompt。
  - 适合做**临时性、针对本次生成的 prompt 微调**，比如高级用户想临时改 prompt。

---

## 2. 推荐方案

### 2.1 绝大多数场景，Prompt 优化应放在 SettingsTab.tsx

- **理由：**
  - Prompt 优化/模板管理属于“全局配置”，影响所有内容生成，适合在设置页统一管理。
  - 你已有完整的模板增删改查、设为默认等功能，用户体验一致。
  - 用户可以根据不同场景预设多套模板，随时切换。
  - 便于后续做权限、版本、团队协作等扩展。

- **操作建议：**
  - 保持现有“Prompt 模板管理”区块，鼓励用户在这里优化和管理 prompt。
  - 可以在模板编辑器里加一些优化建议、示例、变量说明，帮助用户写出更好的 prompt。

### 2.2 如需“临时微调”或“高级自定义”，可在内容生成页面加“高级设置”入口

- **适用场景：**
  - 高级用户希望在某次内容生成时，临时调整 prompt（比如加一句特殊要求）。
  - 你可以在 SocialMediaGenerationModal.tsx 里加一个“高级设置”按钮，点开后允许用户临时编辑本次 prompt（基于当前模板预填）。

- **实现方式：**
  - 默认用 SettingsTab.tsx 里设定的模板。
  - 用户如需临时调整，可在内容生成弹窗点“高级设置”，弹出 prompt 编辑框，编辑后仅本次生效。
  - 这样既不影响全局模板，也满足灵活性。

---

## 3. 结论

- **主力方案**：Prompt 优化、模板管理应放在 SettingsTab.tsx 的“Prompt 模板管理”区块，作为全局配置。
- **可选增强**：如需临时自定义，可在 SocialMediaGenerationModal.tsx 增加“高级设置”入口，允许本次生成时临时编辑 prompt。
