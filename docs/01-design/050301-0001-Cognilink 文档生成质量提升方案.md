以下是一个详细、可操作且优化的技术实施方案，旨在提升 Cognilink Obsidian 插件的文档生成质量。该方案针对单人开发者的限制进行了定制，利用现有功能（如 RAG 检索、嵌入生成、内容去重、原创性检测等），以实现文档质量的提升。核心目标是整合高级提示工程、检索增强生成（RAG）、原创性检查和用户交互，构建一个高效、高质量的文档生成流程。

---

## 问题陈述与优化目标
用户希望改进 Cognilink 插件的文档生成质量，基于现有功能（如 RAG 检索、嵌入存储、内容去重和原创性检测）。作为一个单人开发者，解决方案需要满足：
- **高效**：尽量减少重复工作，复用现有代码。
- **有效**：提升内容的连贯性、相关性和原创性。
- **可行**：避免过于复杂的实现或资源需求。

最终目标是打造一个健壮的生成管道，从 Obsidian 笔记生成高质量、适应平台的原创文档，并提供清晰的可追溯性和用户控制。

---

## 技术实施方案

### 概述
增强的文档生成管道将包括以下模块：
1. **高级提示工程**：支持可定制、平台特定的模板，动态变量替换。
2. **优化 RAG**：智能检索，结合过滤、去重和上下文组装，控制令牌限制。
3. **LLM 微调（轻量可选）**：通过参数高效微调（PEFT）实现风格适配。
4. **原创性检测**：段落级相似性检查，并在 UI 中高亮显示。
5. **工作流自动化**：端到端流程，集成用户反馈和质量评估。

以下是每个模块的详细实现步骤、代码片段和测试方法。

### 1. 高级提示工程

#### 目标
设计一个灵活的、平台特定的提示系统，确保生成的内容符合 Twitter、Xiaohongshu 或 WeChat 等平台的语气、风格和长度要求。

#### 实现
- **模板存储**：将模板以 JSON 格式存储在 `settings.rag.promptTemplates` 中，通过 `PromptTemplateService` 加载。
- **动态变量**：支持 `$theme`、`$context`、`$pinned`、`$platform` 和 `$length` 等变量。
- **UI 集成**：在 `SettingsTab` 中添加模板编辑器，供用户自定义。

#### 代码示例
```typescript
// src/services/PromptTemplateService.ts
interface PromptTemplate {
  id: string;
  name: string;
  platform: string;
  content: string;
}

class PromptTemplateService {
  private templates: PromptTemplate[];
  constructor(templates: PromptTemplate[]) {
    this.templates = templates || [
      { id: "twitter", name: "Twitter 帖子", platform: "twitter", content: "生成一条不超过280字的推文，总结 $theme，包含 $context。添加1-2个标签和一个问题。" },
      { id: "xiaohongshu", name: "小红书笔记", platform: "xiaohongshu", content: "写一篇300字的 $theme 笔记，结合 $context 的生动描述。使用表情符号和‘先马住！’。" },
    ];
  }

  render(platform: string, vars: Record<string, string>): string {
    const template = this.templates.find(t => t.platform === platform) || this.templates[0];
    return template.content.replace(/\$\{(\w+)\}/g, (_, key) => vars[key] || "");
  }
}
```

#### 集成
- 在主工作流中调用 `promptTemplateService.render(platform, { theme: query, context: assembledContext })`。

### 2. 优化 RAG 管道

#### 目标
增强检索和上下文组装，确保提供高度相关、简洁且令牌高效的内容作为 LLM 输入。

#### 实现
- **检索**：使用 `EmbeddingService.findRelevantNotes`，支持可配置过滤（如文件夹、标签）。
- **去重**：通过 `deduplicateNotes` 设置相似性阈值（如 0.98）。
- **上下文组装**：优先使用固定内容，再加入高相关性笔记，注意令牌限制下的截断或总结。

#### 代码示例
```typescript
// src/services/RAGService.ts
class RAGService {
  constructor(private embeddingService: EmbeddingService, private aiService: AIService) {}

  async runRAGPipeline(query: string, topK: number, threshold: number, dedupThreshold: number): Promise<string> {
    // 1. 检索笔记
    const notes = await this.embeddingService.findRelevantNotes(query, topK, threshold);
    
    // 2. 去重
    const deduped = this.deduplicateNotes(notes, dedupThreshold);
    
    // 3. 组装上下文，管理令牌
    const pieces = deduped.map((n, i) => ({
      id: n.path,
      content: `${i + 1}. ${n.content}`,
      pinned: n.pinned || false,
    }));
    const { context } = await assembleContext({
      pieces,
      maxTokens: 2048, // 可通过设置调整
      provider: "openai",
      summaryFn: async (content) => `${content.slice(0, 50)}...`, // 简单截断
    });
    
    return context;
  }

  private deduplicateNotes(notes: Note[], threshold: number): Note[] {

      if (!unique.some(u => this.cosineSimilarity(u.embedding, note.embedding) > threshold)) {
        unique.push(note);
      }
    }
    return unique;
```

#### 目标

#### 实现
- **检测**：将内容分段为段落，与笔记嵌入计算相似性。
- **UI**：在 `PreviewModal` 中集成高亮和提示。

#### 代码示例

```typescript
interface OriginalityResult {
  text: string;
  similarity: number;
  sourcePath: string;
}

class OriginalityService {
  constructor(private embeddingService: EmbeddingService) {}

  async checkOriginality(content: string, threshold: number = 0.8): Promise<OriginalityResult[]> {
    const segments = content.split("\n\n");
    const embeddings = await this.embeddingService.loadEmbeddingsIndex();
    const results: OriginalityResult[] = [];

    for (const segment of segments) {
      const embedding = await this.embeddingService.generateEmbedding(segment);
      let maxSimilarity = 0;
      let sourcePath = "";
      for (const [path, note] of Object.entries(embeddings)) {
        const sim = this.cosineSimilarity(embedding, note.embedding);
        if (sim > maxSimilarity) {
          maxSimilarity = sim;
          sourcePath = path;
        }
      }
      results.push({ text: segment, similarity: maxSimilarity, sourcePath });
```

### 5. 工作流自动化

#### 目标
从输入到输出实现流程自动化，包含质量检查和用户反馈。

#### 实现
- **步骤**：查询 → 检索 → 组装 → 生成 → 检查原创性 → 预览 → 插入。
- **自动化**：使用 `WorkflowService` 协调。

#### 代码示例
```typescript
// src/services/WorkflowService.ts
class WorkflowService {
  constructor(
    private ragService: RAGService,
    private promptService: PromptTemplateService,
    private aiService: AIService,
    private originalityService: OriginalityService
  ) {}

  async runWorkflow(query: string, platform: string): Promise<string> {
    const context = await this.ragService.runRAGPipeline(query, 8, 0.7, 0.98);
    const prompt = this.promptService.render(platform, { theme: query, context });
    const content = await this.aiService.generateContent(prompt);
    const originality = await this.originalityService.checkOriginality(content);
    
    if (originality.some(r => r.similarity > 0.9)) {
      console.warn("检测到高相似性，建议修改:", originality);
    }
    
    return `${content}\n\n## 来源\n${context.split("\n").map((l, i) => `[${i + 1}] ${l}`).join("\n")}`;
  }
}
```

## 在 Obsidian 中测试

### 设置
1. **安装更新**：将上述服务和 UI 组件添加到插件。
2. **注册命令**：添加命令以触发 `WorkflowService.runWorkflow`。

### 测试步骤
1. **打开命令面板**（`Cmd+P`）：
   - 运行“Cognilink：生成文档”。
   - 输入查询（如“AI 伦理”）并选择平台（如“Twitter”）。

2. **验证输出**：
   - **预览模态框**：检查内容、高亮显示和重复段落的提示。
   - **来源**：点击 [n] 链接，确保跳转到正确笔记。

3. **调整设置**：
   - 在 `SettingsTab` 中调整 topK、阈值和提示模板。
   - 重新生成，确认更改反映在输出中。

4. **插入并审查**：
   - 插入到笔记中，验证 Markdown 格式、引用和链接。
